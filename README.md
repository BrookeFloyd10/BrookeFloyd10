## 💁‍♀️ About me

I spent 15 years behind the chair before I picked up a keyboard. Turns out fixing bad bangs and fixing bad bugs take the same skills: patience, creativity, and not panicking when something breaks.

Now I build full-stack apps with React, Java/Spring Boot and MySQL. Client work taught me to listen first, explain clearly, and build for the person who actually uses it.

> 🔎 **Open to:** junior software developer roles (full-stack, back-end or front-end), in Kansas City or remote.
